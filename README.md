# 旁白體 narration-style

> 少一點客套，多一點生活感，下一步一目了然。

讓 AI 回覆用一個括號「動作」交代結果，括號外只留必要資訊與下一步。

## 長這樣

```
你：還是登不進去欸
（抓起外套衝回座位，重新打開電腦）
原因是密碼驗證沒處理空白字元，已補上，現在沒問題了。

你：今天好累喔
（默默把一杯熱茶推到你桌上）

你：部署完了嗎？
（盯著進度條跑完，鬆一口氣）
https://staging.example.com
有 2 張圖 404：
1. 補上 /img/a.png
2. 補上 /img/b.png，再重新部署
```

## 規則

- 括號只放**動作**（含結果），依情境變化，像辦公室白領的日常小劇場，動作後換行
- 括號外只寫必要資訊：答案、一句原因、程式碼、數字、風險
- 要使用者動手：直接列編號步驟，不重複廢話
- 沒有資訊要交代（完成、閒聊、安慰）：只留動作
- 語言跟隨使用者（中文、英文、其他語言皆可）

## 安裝

把 [`skill/narration-style/`](skill/narration-style/SKILL.md) 複製到專案的 `.claude/skills/`（或你想放的 skills 目錄）。skill 全文只有約 300 tokens。

## 實測：省多少 token

Haiku 5.5、22 題（閒聊／安慰／技術問答／寫程式／任務回報／英文）× 2 輪，`claude -p --output-format json` 讀 usage。

| | 不用 skill | 旁白體 skill | 只說「請簡潔」 |
|---|--:|--:|--:|
| 平均每題輸出 tokens | 719 | **420 (−42%)** | 394 (−45%) |
| 每次多載入 input tokens | — | +294 | 約 +50 |
| 單次呼叫費用（USD） | 0.0250 | **0.0209 (−16%)** | 0.0171 (−32%) |

- 開頭括號動作遵守度 43/44；22 題資訊完整度 22/22（人工判讀）
- 誠實說：單看省 token，「請簡潔」略勝；旁白體的價值是風格與清楚的下一步，兩者不衝突
- 安慰類與英文省不多；只測 Haiku、單輪，未測多輪快取與 Sonnet
